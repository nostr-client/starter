# starter

**Join nostr in 60 seconds.** No signup, no email, no company: make a key,
write your profile, follow a few good people, say hello.

**Live:** https://nostr-client.github.io/starter/

Four steps, three published events (kind 0 profile, kind 3 contacts, kind 1
`#introductions` hello), and — because every nostr-client app shares one
origin and one session format — finishing the flow leaves you **already
logged in** to [zen](https://nostr-client.github.io/zen/),
[micro](https://nostr-client.github.io/micro/),
[monty](https://nostr-client.github.io/monty/) and
[reader](https://nostr-client.github.io/reader/).

The starter pack renders only accounts whose profiles actually resolve from
relays, each with an opt-out checkbox. The key is shown once with a
save-it warning and a nudge toward moving it into a NIP-07 extension.

Part of [nostr-client](https://github.com/nostr-client). AGPL-3.0-or-later.
